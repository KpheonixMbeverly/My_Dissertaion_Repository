## 研究问题

到 2026 年 10 月，70 个大中城市的二手房价格全部低于 2021 年 7 月的水平，此后 86% 的城市-月份在下跌。70 城平均已连续下跌 63 个月，累计约 27 个对数点（约 −24%）；2014–15 年那轮只跌了 11 个月，约 −5%。

按揭贷款机构和开发商在许多城市都有住房敞口，五分之二的城镇家庭拥有不止一套住房（中国人民银行，2020）。把持有分散到多个城市是应对本地风险的常用办法，但它只能抵御各城不共有的那部分下跌。本研究的主问题是：**在 2021–26 年中国住房下行中，跨城持有住房能分散哪些房价下跌风险，又有哪些分散不了**？

三个子问题先把城市之间的风险和时间上的风险分开，再追问原因：

- **RQ1 城市之间（选城风险）**：多持有几个城市，能把“选中跌得最惨的城市”带来的损失减少多少？这些城市能否事先根据对全国市场的敏感度或城市实力识别出来？
- **RQ2 时间上（坏月份风险）**：多持有几个城市，能消除最差月份损失中的多少？在全国下跌的月份，或者与 2015–21 年上行期相比，分散的效果是否更弱？
- **RQ3 机制**：哪些下跌前的城市特征，与分散能消除的那部分跌幅、与止跌的早晚有关？

限购限制了家庭跨城购房，所以这里的组合只用来度量风险，不是投资策略。研究是描述性的，不对政策或城市特征作因果判断。主样本是国家统计局的二手住宅价格指数，新建商品住宅指数作对照。

**为什么从“敏感度”改成问“分散”**。11 月 26 日的主问题是“对全国市场最敏感的城市，是否就是累计跌得最深的城市”。正式结果没有发现两者重合（见下文 RQ1），在那个问法下，分位数方法只是附加的检验。全文的因子分解本来就把每个城市的累计跌幅分成两块：按敏感度折算的全国部分，持有再多城市也平均不掉；城市自身的偏离，可以平均掉。所以 11 月 27 日把主问题改成分散：这两块各有多大，分散在最差的月份是否失效。前几部分的结果都落到这个问题上，分位数回归也有了直接要回答的问题。经过见[研究思路的演变](#研究思路的演变)。

## 模型与统计量

全文用同一个因子分解。yᵢₜ 是城市 i 二手房指数的月度对数变化（%），f₋ᵢ,ₜ 是其余 69 城的平均，下跌期 2021-08 至 2026-10 共 T = 63 个月：

- yᵢₜ = aᵢ + βᵢ·f₋ᵢ,ₜ + eᵢₜ
- Dᵢ = Σₜ yᵢₜ = β̂ᵢ·Fᵢ + T·âᵢ，其中 Fᵢ = Σₜ f₋ᵢ,ₜ

βᵢ 是城市对全国市场的敏感度。β̂ᵢFᵢ 是按敏感度折算的全国部分，T·âᵢ 是城市自身的偏离。这个拆分是恒等式，只用来说明结构，不作为证据。

**随机组合（RQ1、RQ2）**。仿照 Evans 和 Archer (1968)：对每个持有城市数 n ∈ {1, 2, 3, 5, 10, 20, 35, 70}，随机抽 10,000 个城市组合（n = 1 为 70 个单城，n = 70 只有一个组合），2021 年 7 月末等额买入，持有到 2026 年 10 月，中间不调仓。组合是随机抽的，不是事后挑的，所以衡量的是没有先见之明时的分散。

- 选城风险：CVaR₁₀(n) 是最差一成组合的平均累计跌幅；Δ_cross(n) = CVaR₁₀(1) − CVaR₁₀(n)。
- 坏月份风险：ES₁₀ 是一个组合（或城市）最差 6 个月的平均月收益；Δ_time(n) = 组合的平均 ES₁₀ − 单城的平均 ES₁₀，正值表示坏月份少跌。
- 上行期对照：同一批十城组合放到 2015-04 至 2021-07（76 个月，取最差 7 个月），比较坏月份尾部距离 G = 月均收益 − ES 在组合里还剩几成（ρ_bad），以及标准差还剩几成（ρ_sd）。

**全国下跌时分散是否打折扣（H-P2，主检验）**。对每个城市和组合，用 2011-02 至 2026-10 的 189 个月估计分位数回归。组合的 yₚₜ 是成员城市变化的平均，全国因子 fₚₜ 取非成员城市的平均，拆成全国涨幅 hₚₜ = max(fₚₜ, 0) 和跌幅 gₚₜ = max(−fₚₜ, 0)：

- Q_τ(yₚₜ | ·) = aₚ(τ) + βₚ⁺(τ)·hₚₜ + βₚ⁻(τ)·gₚₜ + dₚ(τ)·yₚ,ₜ₋₁，τ ∈ {0.25, 0.5, 0.75}
- 平时的坏端距离 w₀ = a(0.5) − a(0.25)；全国每多跌 1 个百分点，这一距离拉宽 ω = β⁻(0.5) − β⁻(0.25)
- 保留比：R_w(n)、R_ω(n) 分别是组合的 w₀、ω 相当于其成员城市平均值的几成；θ(n) = R_ω(n) − R_w(n)

取平均本身会让所有宽度变窄，所以不拿组合的 ω 直接和单城比，而是比较两个保留比。θ > 0 说明全国下跌时新增的分化在组合里留得更多，也就是分散在大跌时打折扣。

## 目前的结果

括号内为自助法 95% 区间，MDE 是最小可检测效应（2.5 × 自助标准误）。数字出自各部分的结果报告，文件位置见 [results/README.md](results/README.md)。第五部分的 11 条实现约定和拟议偏离（[deviations_proposed.md](results/hp_portfolio/deviations_proposed.md)）还没有经作者确认。

### 这一轮下跌（论文第 3 节）

|---|---|---|
| 有多广、多久 | 2021-08 至 2026-10，86% 的城市-月份在跌；70 城累计全部为负，从成都 −4.8 到唐山 −39.7 个对数点，平均 −27.2；连跌 63 个月，此前两轮各 10、11 个月 | 典型事实，只作描述 |

### RQ1 城市之间：选城风险（论文第 5 节）

| 问题 | 结果 | 结论的写法 |
|---|---|---|
| 能分散多少 | 最差一成组合的平均累计跌幅 CVaR₁₀：1 城 30.45%，10 城 26.17%，70 城 23.66%。Δ_cross(10) = 4.28 [3.33, 5.17] 个百分点；Δ_cross(70) = 6.79 [5.45, 7.96] | 持有 10 城比只持有 1 城，选城最不利的一成情形少跌 4.28 个百分点。持有全部 70 城仍跌 23.66%，这是分散不掉的部分；等权买入持有不改变平均跌幅 |
| 能否事先认出重跌城市（H-P5） | 用 2011-01 至 2021-07 估计的事前敏感度：ρ(β_pre, −D) = −0.13 [−0.36, 0.11]。跌得最深的 17 城与事前 β 最高的 17 城只重合 2 个，随机期望 4.13；选事前 β 最低的 10 城等权持有，跌幅在随机十城组合中位于第 47.6 百分位，接近中位数 | 事前敏感度不能识别重跌城市。同期的敏感度也认不出：ρ(D, β) = 0.13 [−0.42, 0.59]（第二部分） |
| 谁先止跌（H-P4） | 城市实力 S（六项 2016–21 年特征的第一主成分）与最近 6 个月（2026-05 至 2026-10）累计变化的秩相关 ρ(S, R6) = 0.36 [0.12, 0.59]；按 S 三等分，已见底的城市分别占 8.7%、13.0%、34.8% | 实力强的城市先止跌。实力强的城市对全国冲击也更敏感：ρ(S, β) = 0.62 [0.35, 0.74]，通过了薄市场检验（第二部分） |
| 跨区域是否更好（H-P3） | 五城组合，跨区域减同区域的 CVaR₁₀：+0.095 [−1.083, 0.382] 个百分点 | 跨区域与同区域差别不明显 |

### RQ2 时间上：坏月份风险（论文第 6 节）

| 问题 | 结果 | 结论的写法 |
|---|---|---|
| 能分散多少 | 最差 6 个月的平均月收益 ES₁₀：1 城 −1.163%，10 城 −0.935%，70 城 −0.910%。Δ_time(10) = 0.228 [0.178, 0.276] 个百分点 | 坏月份平均少跌 0.23 个百分点，约五分之四分散不掉 |
| 全国下跌时是否打折扣（H-P2，主检验） | 闸门：单城的 ω̄ = 0.090 [0.026, 0.172]，单城层面看得到全国下跌时的变宽，进入判定。θ(10) = 0.081 [−0.348, 0.483]，MDE = 1.001 | 大跌时的变宽与平时的宽度被分散掉的比例相当，多保留的不超过 4.83 成。MDE 约为 1，检验力很低，只能写“没有发现打折扣”，不能写“不打折扣” |
| 与上行期比（H-P6） | 十城组合保留的坏月份尾部距离：上行期 0.513，下行期 0.693，差 0.180 [0.039, 0.264]；标准差保留比之差 0.130 [0.005, 0.233] | 下行期坏月份的分散效果比上行期差；平常月份也有类似的差别 |
| 稳健性与基准 | 坏月份比值减标准差比值（R1，按正态模拟中心化）：0.020 [−0.065, 0.092]。独立冲击基准下 R_w(10) 的模拟 95% 范围为 [0.389, 0.457]，实际为 0.392 | 与 H-P2 一致；扣除全国因子之后，没有发现城市自身的冲击成群出现 |
| 是否一起深跌（第一、三部分） | 同时深跌超出高斯基准 +0.03 [−0.05, 0.11]；下尾减上尾 +0.09 [−0.09, 0.20]；分位数因子模型 QF1 +0.034 [−0.041, 0.109]；单城下尾斜率的上升主要是尺度效应（H4） | 没有超出相关性的同时深跌，写成上限（区间上端约 +0.11） |

### RQ3 机制（论文第 7 节，尚未运行）

[附录 B 的方案草稿](docs/analysis_plan_hp_part4b_mechanism_20261127.md)把 RQ3 分成三步，全部用下跌前的城市特征和秩相关，不作因果解释：

- 敏感度从哪里来：下跌前估值越高（2016–20 年房价收入比）的城市，β 是否越大（H-B1）。
- 城市自身的跌幅从哪里来：控制 β 后，下跌前供给积压越多、人口增长越慢的城市，是否跌得更深（H-B2a 为主检验，H-B2b）。供给积压是 2016–20 年住宅用地成交面积相对城市人口规模和 2010–20 年人口增长的剩余部分。
- 止跌早晚从哪里来：控制限购解除的早晚后，人口增长快、供给积压少的城市，最近 6 个月是否走得更好（H-B3a、H-B3b）。实力最强的城市限购持续得最久，控制这一项才能区分“靠本地需求止跌”和“靠放松限购止跌”。

不直接用 T·âᵢ 作因变量，是因为任何与 β 相关的变量都会机械地与 Dᵢ − β̂ᵢFᵢ 相关。锁定前要作者确认三件事：主区间用双向自助还是只对城市重抽；H-B1 是否保留（它与已看过的 S–β 结果高度重合）；H-B3 放在附录 B 还是单独锁定。

## 研究流程

- **先锁定，后运行**：每份分析方案在正式估计前写定，计算 SHA-256 并记入 [docs/plan_locks.md](docs/plan_locks.md)，然后才运行。锁定后的改动只追加在方案末尾的“偏离记录”里，正文不动。第一至第三部分的多数点估计在锁定前的探索中已经看过，所以称“分析方案锁定”，不称预注册；第五部分锁定前没有看过任何组合层面的统计量，已看过的单城结果在方案第 2 节逐项披露。
- **只研究一轮**：2011 年以来只有三轮下跌，跨轮比较只作描述。下跌期按全国累计指数的拐点划定；2015-04 至 2021-07 的上行期只作对照。
- **否定结论写成上限**：报告区间上端和 MDE；12 月再用阳性对照模拟说明各项检验的检验力（附录 C）。
- **推断**：6 个月块的循环块自助法，所有城市共用同一组块。主设定 B = 999，分位数回归类的检验次数少一些（H4 为 299，分位数因子模型和 H-P2 为 499）；整轮跌幅这类已经实现的城市间结果，对城市重抽；城市截面的相关同时报告双向自助（月份按块重抽、城市有放回重抽）。

## 复现

需要 Python 3.9 及以上。第一至第三部分和附录 A 的结果在 Python 3.13、numpy 2.5、scipy 1.18、pandas 3.0 下得到；第五部分在 Python 3.9.7、NumPy 1.20.3、SciPy 1.7.1、pandas 1.3.4 下得到。

```bash
pip install -r requirements.txt
```

还需要两份本地数据（不在仓库内）：

- `ZIP`：从 CSMAR 导出的 70 城住宅价格指数压缩包，内含 `CME_MResidSalesPriceIndices.csv`。脚本直接读压缩包。
- `PANEL_DIR`：城市特征数据目录，只有第二部分用到。目录里需要有 `【stata文件】各城市面板数据合集 2000-2024年 200+指标合集.dta`、`整理结果/hpr_panel_70city_monthly.csv` 和 `整理结果/panel_35city_yearbook.csv`。

在仓库根目录运行。`sec` 为二手房，`new` 为新房；自助法部分单个命令约需几分钟到十几分钟。

```bash
ZIP="/path/to/CME_MResidSalesPriceIndices_70城住宅价格指数_20261119.zip"
PANEL_DIR="/path/to/中国房地产统计年鉴+面板数据"

# 第一部分

python scripts/hp_run_hetero.py "$ZIP" "$PANEL_DIR" sec main    999 results/hp_hetero/sec
python scripts/hp_run_hetero.py "$ZIP" "$PANEL_DIR" sec block3  499 results/hp_hetero/sec
python scripts/hp_run_hetero.py "$ZIP" "$PANEL_DIR" sec block12 499 results/hp_hetero/sec
python scripts/hp_run_hetero.py "$ZIP" "$PANEL_DIR" new points  0   results/hp_hetero/new
python scripts/hp_run_hetero.py "$ZIP" "$PANEL_DIR" new main    999 results/hp_hetero/new

# 第三部分
python scripts/hp_run_qfm.py "$ZIP" sec points 0   results/hp_qfm/sec
python scripts/hp_run_qfm.py "$ZIP" sec boot   499 results/hp_qfm/sec
python scripts/hp_run_qfm.py "$ZIP" new points 0   results/hp_qfm/new
python scripts/hp_run_qfm.py "$ZIP" new boot   499 results/hp_qfm/new

# 附录 A
python scripts/hp_run_dating.py "$ZIP" results/hp_dating
python scripts/hp_run_hetero_p3alt.py "$ZIP" "$PANEL_DIR" sec results/hp_dating/sec_p3alt

# 第五部分：只需要 ZIP，城市实力指数从仓库里的 results/hp_hetero/sec_cities.csv 重算
# B 必须取下面的值（脚本会检查）；HP_PORTFOLIO_WORKERS 是分位数回归的进程数，默认 1
export HP_PORTFOLIO_WORKERS=8
python scripts/hp_run_portfolio.py "$ZIP" points    0   results/hp_portfolio

python scripts/hp_run_portfolio.py "$ZIP" boot_time 999 results/hp_portfolio
python scripts/hp_run_portfolio.py "$ZIP" bench_qr  199 results/hp_portfolio
python scripts/hp_run_portfolio.py "$ZIP" boot_qr   499 results/hp_portfolio
```

随机种子写在脚本里：第一至第三部分主要是 20261124 及其派生值，第五部分是 20261127（`boot_time` 为 +1）。用同样的脚本和命令重跑，应得到相同的结果；改动脚本中的计算顺序会改变随机数流，自助区间会有小幅差异。第五部分脚本运行前会核对方案文件的 SHA-256，不一致就停止；随机输入先生成并存在本地忽略的 `results/hp_portfolio/tmp/`，中断的自助模式可以接着跑。8 个进程下，第五部分全量运行约 12 分钟。
