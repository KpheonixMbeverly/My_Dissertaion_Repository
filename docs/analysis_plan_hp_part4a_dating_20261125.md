# 分析方案附录 A（第四部分）：下跌期按拐点重新划分（偏离更正）（2026-11-25）

本附录更正第一部分方案（`analysis_plan_hp_20261124.md`）中下跌期窗口 D1、D2 的划分。它在新窗口的任何推断（自助法区间）计算之前写定并锁定。第一、二、三部分的其他锁定内容不变。

## 1. 问题

第一部分按日历年锁定 D1 = 2014-01 — 2015-12、D2 = 2022-01 — 2025-12。核对全国二手房平均环比后发现：
- D1 的 24 个月中有 13 个月全国平均在上涨（2014 年 1—4 月尚未开始下跌，2015 年 4—12 月已经回升），实际下跌只有约 11 个月。
- 这一轮下跌从 2021 年 8 月就已开始，2021 年 8—12 月被划进了 P2 末尾，不在 D2 内。

因此 H1（D2 的广度高于 D1）的锁定结果主要反映窗口划分，而不是两轮下跌的差别。这是方案设计的疏漏。

## 2. 事先披露（已经看过的结果）

写定本附录时已经看过：
- 2013-06 — 2016-06 和 2021-01 — 2022-06 两段时间，二手房和新房的逐月全国平均环比，以及逐月下跌城市占比；2025-06 — 2026-10 的同类数字。
- 按第 3 节规则得到的拐点月份。
- 二手房广度（下跌的城市-月份占比）的点估计：D1* = 0.832；2021-08 — 2025-12 = 0.858；2021-08 — 2022-06 = 0.758；锁定窗口 D1 = 0.537、D2 = 0.865。

尚未看过：新窗口下的全部自助法区间、`share05`、新房 H1、B2、累计跌幅和持续时间之外的其他描述统计。所以 H1* 不是确证性检验，正式运行只为它增加推断。

## 3. 拐点划分规则

- 全国二手房累计指数：Iₜ = Σ_{s≤t} ȳₛ，其中 ȳₛ 是 70 城二手房 yᵢₛ 的等权平均。
- 第一轮：高点 = Iₜ 在 2013-01 — 2014-12 内的最大值所在月；低点 = Iₜ 在 [高点, 2016-12] 内的最小值所在月。
- 第二轮：高点 = Iₜ 在 2019-01 — 2022-12 内的最大值所在月；低点 = Iₜ 在 [高点, 2026-10] 内的最小值所在月；如果低点就是数据最后一个月，视为尚未见底，窗口截至 2026-10。
- 下跌期窗口 = 高点次月 — 低点。

结果：
- **D1\* = 2014-05 — 2015-03**（11 个月）；
- **D2\* = 2021-08 — 2026-10**（63 个月，尚未见底）。

新房按同一规则得到的窗口为 2014-05 — 2015-04、2021-09 — 2026-10，只用于稳健性（见第 4 节）。主分析中两个市场统一使用二手房的窗口，因为 B2 需要在同一窗口内比较新房和二手房。

## 4. 检验

推断设定与第一部分相同：每个窗口内独立做循环移动块自助，块长 6 个月，B = 999，种子 20261124；报告点估计、自助标准误、双侧 95% 百分位区间和 MDE = 2.5 × 标准误。D1\* 只有 11 个月，另报告块长 3 的结果。

- **H1\***（二手房，主检验）：breadth(D2\*) − breadth(D1\*) > 0；同时报告 share05（环比 ≤ −0.5 的城市-月份占比）的差值。
- **H1\*-等长**（稳健性）：D2\* 的前 11 个月（2021-08 — 2022-06）对 D1\*，排除两轮长度不同的影响。
- **H1\*-新房**：新房用同样的二手房窗口；另报告新房用自己的拐点窗口的结果。
- **B2\***：gap5010、gap9050 的新房减二手房差距在 D2\* 与 D1\* 之间的变化，双侧。
- **描述统计（无推断）**：每轮的持续月数、高点到低点（或到 2026-10）的累计跌幅（∑ȳ，对数百分点）、平均每月跌幅；按"距高点月数"对齐的逐月下跌城市占比（作图）。

## 5. 判定规则

| 结果 | 正文表述 |
|---|---|
| H1\* 区间含 0 | 两轮下跌期间的广度相当，都是八成以上的城市在跌；"全面下跌"对两轮都成立。这一轮的突出特点是持续时间，用描述统计说明 |
| H1\* 区间在 0 以上 | 这一轮比上一轮更普遍；同时报告持续时间 |
| H1\* 区间在 0 以下 | 这一轮在下跌期间反而不如上一轮普遍，但持续得久得多 |

锁定的日历年窗口结果照常报告，作为原始预注册结果，并说明它为什么不能用来比较两轮下跌。

## 6. 第三章稳健性：P3 从 2021-08 开始

按第二部分方案的 `points` 模式（只报点估计，不参与判定），把 P3 改为 2021-08 — 2026-10，重算闸门 M1—M4、H5—H9 的点估计，与锁定结果并列。其余设定不变（69 城、实力指数用 2016—2021 年均值）。注意：实力指数的取值窗口 2016—2021 与新 P3 有 5 个月重叠，这一点在结果中说明。
