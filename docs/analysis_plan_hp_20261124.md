# 分析方案锁定：全面下跌，但并不同步？（2026-11-24）

本文件在正式估计前写定，此后改动只记入文末"偏离记录"。这不是严格意义的预注册：下列多数统计量的点估计已在 2026-11-24 的探索性试算中看过，假设方向受其影响。正式运行只增加推断（自助法区间）和稳健性检验，不改变统计量定义。

## 1. 数据

- 来源：CSMAR `CME_MResidSalesPriceIndices`（`data/raw/csmar/CME_MResidSalesPriceIndices_70城住宅价格指数_20261119.zip`），Datasign = A（环比，上月 = 100）。
- 市场：二手住宅 `Nsecondresid`（主样本）；新建商品住宅 `Newcommerresid`（对照）。
- 城市：70 个大中城市；剔除代码 156（"中国"，全国汇总行）。
- 变量：y(i,t) = 100 × ln(环比指数 / 100)，即月度对数涨跌（%）。
- 样本：2011-01 至 2026-10（190 个月）。

## 2. 时期

| 代号 | 区间 | 说明 |
|---|---|---|
| P1 | 2011-01 — 2015-12 | 统一调控与全国性松绑（因子正负月份都多） |
| P2 | 2016-01 — 2021-12 | 因城施策（繁荣期） |
| P3 | 2022-01 — 2026-10 | 全面下跌与放松 |
| D1 | 2014-01 — 2015-12 | 上一轮下跌 |
| D2 | 2022-01 — 2025-12 | 本轮下跌（与 D1 对比时使用） |

## 3. 统计量

全国因子 f(−i,t)：其余 69 城 y 的等权平均（原始百分点，不标准化）。汇总方式：70 城均值为主，同时报告中位数。

- **H1 广度**：Breadth = 各月"y < 0 的城市比例"的时期均值。检验 Breadth(D2) − Breadth(D1) > 0。另报告固定门槛（y ≤ −0.5）的城市比例。
- **H2a 共同趋势**：S_raw = 1 − Σ(y − ȳₜ)² / Σy²（对城市和月份求和，ȳₜ 为当月 70 城均值）。检验 S_raw(P3) − S_raw(P1) > 0 且 S_raw(P3) − S_raw(P2) > 0。
- **H2b 同步波动**：S_dm = 同一公式作用于"各城减去本期自身均值"后的数据。检验 S_dm(P3) − S_dm(P1) < 0。同时报告分期标准化 PCA 第一主成分方差占比 PC1 及其差。
- **H3 同时深跌**：在每个时期内，用本期分位数作阈值，Cᵢᴸ = Pr(yᵢ ≤ qᵢ(0.25) | f ≤ q_f(0.25))，Cᵢᵁ 为上尾对应量；Cᵢᴳ 为同等正态得分相关下高斯 copula 的值。三个检验量：ΔCᴸ = C̄ᴸ(P3) − C̄ᴸ(P2) > 0；超出量 E = mean(Cᵢᴸ − Cᵢᴳ)(P3) > 0；不对称 A = mean(Cᵢᴸ − Cᵢᵁ)(P3) > 0。H3 成立需三者同时成立。
- **H4 下尾斜率**：在 P1 逐城估计 Q_τ(y | f, |f|, y₋₁)，τ ∈ {0.25, 0.75}，得 bᵢ(τ)、cᵢ(τ)；在 P3 逐城估计 Q_τ(y | f, y₋₁) 得 λᵢ(τ)。实测下尾倾斜 T_obs = λᵢ(0.25) − λᵢ(0.75)；尺度效应预测 T_pred = [bᵢ(0.25) − cᵢ(0.25)] − [bᵢ(0.75) − cᵢ(0.75)]。检验 mean(T_obs − T_pred) > 0。对 P2 报告上尾的对应量（预测用 b + c）。
- **B1 两套指数**：P3 内新房减二手房的差：城市月均涨跌、S_raw、S_dm、PC1、C̄ᴸ。双侧检验。
- **B2 下尾形状**：同城时间序列分位数间距 G = P50 − P10，报告 mean(G_new − G_sec) 在 D2 的值及其相对 D1 的变化；P90 − P50 同理。

## 4. 推断

- 时期内循环移动块自助法：按月份抽块（块长 6 个月），同一月份的 70 城和两个市场一起抽取，保留截面相关与市场配对。
- 每次抽样重新计算全部统计量（因子、阈值、秩、分位数回归）。
- 跨期比较：各时期独立抽样。
- B = 999（H4 因含分位数回归，B = 299）。报告点估计、自助标准误、双侧 95% 百分位区间。
- 判定：区间不含 0 且方向与假设一致，记为"支持"。

## 5. 稳健性（预先指定，不参与判定）

1. 块长 3 和 12 个月。
2. 去季节：去掉各城日历月份效应（按年内去均值后估计）。
3. 3 个月累计涨跌。
4. H3 阈值改为 10%。
5. 构造 f 时剔除本城所在区域（东部、中部、西部、东北）。
6. 新房市场重复全部检验。

## 6. 判定规则

按顺序对照，第一条符合的即为结论：

| 顺序 | 结果 | 结论 |
|---|---|---|
| 1 | H1、H2a、H2b 成立，H3 不成立 | 广而不齐：下跌的全国性体现在趋势，不体现在同时深跌 |
| 2 | H3 成立 | 下跌期出现超出相关性的同时深跌 |
| 3 | H2b 不成立 | 下跌既广又同步 |
| 4 | H1 或 H2a 不成立 | 本轮下跌的全国性弱于预期，重新审视问题 |

H4、B1、B2 单独报告：H4 成立则作为尾部特有发现补充；不成立则写明"下尾斜率上升主要是尺度效应"。
