# 蒙特卡洛模拟：初步结果（2026-11-18）

> **状态：初步结果，不能直接写进论文。** 每种设定只跑了 3 到 5 次重复，数据是通用的模拟数据，
> 持续性参数凭经验设定，没有按中国数据校准。这里记录的是方向性的发现，用于和导师讨论研究设计。
> 最终结果要等用真实面板做半模拟（第二轮）之后再定。

## 1. 目的

在与本研究样本量相近的条件下（260 个月、100 个指标、120 个月滚动窗口、约 140 次样本外预测），检验：

1. 当信息确实藏在个别指标里时，"完整模型（FA-QR）对纯因子模型（FO-QR）"的样本外比较能否识别出来（检验的分辨力）；
2. 当信息只在共同因子里时，比较会不会误判完整模型更好（误报）；
3. 完整模型选出的指标有多少是真实信号。

本轮只检验 2×2 设计中的横向比较（D 对 C）：模拟指标不分组，模型使用全部指标。纵向比较（金融信息有没有用）留待第二轮。

## 2. 设定

数据生成见 `src/gar/simulate.py`：

- 指标面板 = 3 个共同因子 × 随机载荷 + 个别成分；因子和个别成分都是 AR(1)。
- 目标变量 = 截距 + 自身滞后（仅高持续性一轮）+ 因子部分 + 个别成分部分 + 尺度随某个个别成分变化的厚尾误差（t 分布，自由度 3）。
  最后一项让某个指标只影响尾部、不影响中位数。
- 四种"世界"：纯稠密（只有因子有信息）、纯稀疏（只有 5 个个别成分有信息）、混合（两者都有）、情况 A（一个只作用于 10 个指标的弱因子，主成分会漏掉它）。
- 两种因子强度：强（载荷不缩放）、弱（载荷乘以 p 的 -0.2 次方）。
- 模型：HIST（历史分位数）、FO-QR、SO-QR、FA-QR；h = 1；分位数 0.10、0.25、0.50。
- "DM 拒绝率"指单边 DM 检验在 10% 水平上判定该模型优于 FO-QR 的重复占比：在应当胜出的世界里是分辨力，在不应胜出的世界里是误报率。
- 覆盖率指实际值落在预测分位数以下的比例，理想值等于分位数本身。

复现命令：

```
python scripts/01_monte_carlo.py --reps 5 --jobs 4
python scripts/01_monte_carlo.py --rho_f 0.9 --rho_u 0.8 --rho_y 0.5 --reps 3 --jobs 4
```

本文件夹下的 `summary_low_persistence.csv` 和 `summary_high_persistence.csv` 是两轮的完整汇总表。

## 4. 初步发现

1. **25% 和 50% 分位数上，比较有分辨力。** 在个别指标确实有信息、因子较强的世界里，完整模型基本每次都胜出，DM 检验基本都能识别出来；在信息只在强因子里的世界里没有误报。
2. **10% 分位数上，分辨力很弱，而且在高持续性下系统性地偏向纯因子模型。** 低持续性时两者大致打平；高持续性时，8 种设定中有 6 种完整模型的损失高 4% 到 5%（另两种为弱因子下的纯稠密和情况 A，大致持平或略低），覆盖率也偏高（约 11% 到 16%，理想值 10%）。原因是每个窗口只有约 108 个样本对，10% 分位数附近的观测太少。
3. **弱因子会被误当成个别指标的信息。** 在"只有共同因子有信息、但因子较弱"的世界里，检验在 20% 到 67% 的重复中误判完整模型更好，持续性越高越严重。机制与 Wang 论文中讨论的一致：主成分没有把弱因子提取干净，残留的共同信息被 lasso 选进来。
4. **选中的指标有大量假信号，且持续性越高越难选对。** 25% 和 50% 分位数上，5 个真实信号在低持续性下平均选中约 4 个，高持续性下约 1.7 到 3 个；每个窗口选中的指标总数则远多于 5 个。
5. **持续性越高，完整模型的优势越小。** 在纯稀疏和混合世界里，25% 分位数上的损失降幅从 14% 到 21% 降到 7% 到 8%（强因子），弱因子的混合世界里几乎没有降幅。部分原因是机械性的：目标的自身滞后解释了更多变动，个别指标的相对贡献随之变小。

## 5. 对研究设计的含义（待与导师讨论）

1. 主要的尾部分位数改为 **0.25**，0.10 作为补充报告，并用模拟说明其分辨力有限。论文中的"下行风险"指增长分布的下四分位，而非危机式的极端下跌。
2. **多取一两个因子（r+1、r+2）的检验是必做项**：完整模型胜出后，若加因子后优势消失，结论应为"共同信息提取不充分"，而非"个别指标有信息"。也可以比较其他确定因子个数的方法。
3. **选中频率只作描述**，不点名"最重要的指标"；增益来源用删组检验在组的层面判断。
4. **"没有显著差异"不能解读为"一个指数就够了"**，要结合模拟得出的分辨力说明。
5. 方法论上的附带发现：以中国在险增长研究常见的样本量，10% 及以下分位数上的预测比较分辨力很低，弱因子容易被误当成个别指标的信息。这可以作为对现有文献的提醒。

## 6. 局限与下一步

- 重复次数太少（3 到 5 次），一次重复的差别就是 20 到 33 个百分点；具体数字不可靠。
- 数据是通用模拟数据；持续性、趋势、危机时期的聚集、1 月缺失、指标分组都没有按中国数据设定。
- 下一步：整理真实面板后做**半模拟**（预测指标直接用真实面板，只有目标变量按已知规则生成，误差从真实残差中重抽），并加入指标分组以检验 2×2 的纵向比较。这一轮的结果写进论文。
