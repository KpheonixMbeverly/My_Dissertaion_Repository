## 2. 城市实力指数 S

六个变量，各取 2016–2021 年均值：

| 代号 | 变量 | 计算 |
|---|---|---|
| x1 | 房地产投资依赖 | 房地产开发投资完成额 / 地区生产总值 |
| x2 | 财政自给率 | 地方一般预算收入 / 地方一般预算支出 |
| x3 | 信贷深度 | 年末金融机构贷款余额 / 地区生产总值 |
| x4 | 收入水平 | ln(人均地区生产总值) |
| x5 | 人口规模 | ln(常住人口) |
| x6 | 限购强度 | 2016-01 — 2021-12 限购月份占比 |

在 69 城之间标准化后做主成分分析，S = 第一主成分得分；符号规定为 x4 的载荷为正。报告载荷和方差占比。

## 3. 城市层面的结果变量

每个时期、每个市场，逐城计算（T 为时期内月数）：

- **累计涨跌 D**：Dᵢ = Σₜ yᵢₜ（时期内对数累计涨跌，%）。在 P3 中 D 越大表示跌得越浅。
- **敏感度 β**：OLS 回归 yᵢₜ = αᵢ + βᵢ · f(−i,t) + eᵢₜ。
- **分解**：由于 OLS 残差之和为零，Dᵢ = Aᵢ + Kᵢ 恒成立，其中
  - 本地成分 Aᵢ = T · αᵢ；
  - 共同成分 Kᵢ = βᵢ · Σₜ f(−i,t)。
- **Dimson 敏感度 βᴰ**：yᵢₜ 对 f(−i,t)、f(−i,t−1)、f(−i,t−2) 回归，βᴰ = 三个系数之和。滞后值取自完整序列（P3 首月用 2021 年 11、12 月的 f）。
- **长期限敏感度 β⁽ʰ⁾**：把 y 和 f 都换成 h 个月重叠累计涨跌后的 OLS 斜率；h = 3 为主，h = 6 只报告。
- **分位数斜率 bᵢ(τ)**：逐城分位数回归 Q_τ(yᵢₜ | f) = aᵢ(τ) + bᵢ(τ) · f(−i,t)，τ ∈ {0.25, 0.50, 0.75}。
- **同时深跌 Cᵢᴸ**：定义同第一部分 H3（阈值 25%，全国因子），并计算高斯 copula 基准 Cᵢᴳ 和超出量 Eᵢ = Cᵢᴸ − Cᵢᴳ。
- **薄市场代理变量**（视为固定的城市特征，不随月份重抽）：
  - Zᵢ：2011-01 — 2026-10 中 y 恰好为 0（环比 = 100.0）的月份占比；
  - ρ1ᵢ：P3 中 OLS 残差 eᵢₜ 的一阶自相关；
  - Vᵢ：ln(2016–2021 年均住宅销售面积)，仅 35 城。

## 4. 统计量与假设

截面关联一律用 69 城之间的 Spearman 秩相关，记为 ρ(S, ·)。偏秩相关 ρ(S, · | 控制变量) 的计算方法：把 S 的秩和结果变量的秩分别对控制变量（控制变量的秩，或城市等级虚拟变量）回归，取两组残差的 Pearson 相关。

### 4.1 薄市场闸门 M（二手房，P3）

**逻辑。** 如果弱城市成交稀少、价格指数被平滑（报价滞后或评估价粘滞），那么同期 β 会低估它们的真实敏感度。这种情况会留下三种痕迹：滞后期载荷为正、残差正自相关、β 随期限拉长而上升。另一种可能是，"实力"只是"市场厚度"的代名词。

- **M1**：ρ(S, βᴰ) > 0；比值 R1 = ρ(S, βᴰ) / ρ(S, β)。
- **M2**：ρ(S, β⁽³⁾) > 0；比值 R2 = ρ(S, β⁽³⁾) / ρ(S, β)。另报告 β⁽⁶⁾。
- **M3**：ρ(S, β | Z, ρ1) > 0。
- **M4**：ρ(S, β | 城市等级虚拟变量) > 0，即等级内部比较。另分别报告二线内部（31 城）和三线内部（35 城）的 ρ(S, β)，这两个不进入闸门。
- **M5**：35 城内 ρ(S, β | V) > 0，只报告，不进入闸门。
- **平滑诊断**（描述性）：ρ(S, βᴰ − β)，若弱城市反应滞后则应为负；以及 ρ(S, ρ1)、ρ(S, Z)。

**闸门规则**：

- 条件 A（平滑）：M1 和 M2 的区间都不含 0，且 R1 ≥ 0.5、R2 ≥ 0.5。
- 条件 B（市场厚度）：M3 和 M4 的区间都不含 0。
- A、B 都满足为**通过**；只满足一条为**部分通过**；都不满足为**不通过**。

### 4.2 主假设（二手房，P3）

- **H5 深度**：ρ(S, D) > 0（实力越强跌得越浅）。〔探索中已看过〕
- **H6 敏感度**：ρ(S, β) > 0（实力越强越敏感）。〔探索中已看过〕
- **H7 错位来源**：ρ(S, A) > 0，即强城市的本地成分更高，抵消了更高 β 带来的更大共同跌幅。同时报告：
  - ρ(S, K)；
  - 截面离散度分解 φ_A = cov(D, A) / var(D)，φ_K = cov(D, K) / var(D)，两者之和为 1。
- **H8 下尾敏感度**：
  - H8a：ρ(S, b(0.25)) > 0。
  - H8b：ρ(S, b(0.25) − b(0.75))，双侧，无方向假设。
- **H9 下尾同时性**：
  - ρ(S, Cᴸ) > 0；
  - ρ(S, E)，双侧。
  - 描述性：按 S 三等分（23/23/23 城）报告各组的平均 D、β、Cᴸ、E；以组内留一均值为因子的组内 Cᴸ；以及 ρ(D, Cᴸ)，即跌得最深的城市是否在全国最差的月份一起深跌。

### 4.3 时期与市场对照（双侧，描述性）

- ρ(S, β) 和 ρ(S, D) 在 P1、P2、P3 中的值，以及差值 P3 − P2、P3 − P1。
- 新房市场重复 4.1–4.2 的全部统计量。它是半独立的重复检验，因为探索中没看过。注意：强城市新房价格受限价和备案价指导，这会压低实测 β，与市场厚度无关。

## 5. 推断

双向自助法，B = 999。每次抽样做两件事：

1. **月份**：在时期内做循环移动块自助（块长 6 个月），70 城和两个市场用同一组月份，按回归设计的行重抽（每行带着 y、f 及其滞后值和累计值）。重新计算 f 和全部城市层面的结果变量。
2. **城市**：独立地对 69 城有放回重抽，在抽到的城市上重新做主成分分析得到 S（符号规则不变），再计算全部秩相关。

其他规定：

- 跨期差值：各时期独立抽月份，共用同一次城市抽样。
- 薄市场代理变量 Z、ρ1、V 只随城市重抽，不随月份重抽。
- 报告点估计、自助标准误、双侧 95% 百分位区间，以及最小可检测效应 MDE = 2.5 × 标准误。
- "支持"：区间不含 0 且方向与假设一致。

## 6. 稳健性（预先指定，只报点估计，不参与判定）

1. 剔除 4 个一线城市。
2. S 改用 2016 年单年值。
3. S 去掉限购占比 x6（限购是政策变量，可能受房价本身影响）。
4. 用 x1–x6 分别替代 S，看哪个变量在驱动结果。
5. 构造 f 时剔除本城所在区域。
6. 去季节数据。
7. 块长 3 和 12 个月（B = 499，不含分位数回归，报区间）。
8. 分位数回归加入本城滞后一期。
9. 用 Pearson 相关替代 Spearman。
10. Cᴸ 阈值改为 10%。

## 7. 判定规则

按顺序对照，第一条符合的即为结论：

| 顺序 | 结果 | 结论 |
|---|---|---|
| 1 | 闸门不通过 | 敏感度差异可能来自指数平滑或市场厚度；第三章只报告深度异质性（已知结论的复核）和测量讨论，不提"强弱错位" |
| 2 | 闸门通过或部分通过，且 H5、H6、H7 都支持 | 强弱错位：实力强的城市跌得浅，但对全国涨跌更敏感；弱城市深跌主要来自本地成分。部分通过时写明哪类测量威胁未排除 |
| 3 | 闸门通过或部分通过，H5、H6 支持，H7 不支持 | 存在错位，但深度差异的来源分解不确定 |
| 4 | H6 支持，H5 不支持 | 只有敏感度异质性 |
| 5 | H5 支持，H6 不支持 | 只有深度异质性（已知） |
| 6 | 都不支持 | 无系统异质性 |

H8、H9 单独报告：

- H8a 支持，则写"敏感度差异在下尾同样存在"。
- H9 用于连接第一部分"未同时深跌"的结论：如果强城市 Cᴸ 更高、而跌得深的城市 Cᴸ 不高，则说明深跌和同时深跌发生在不同城市。

新房结果与二手房方向相反时，在结论中写明，不改判定。
