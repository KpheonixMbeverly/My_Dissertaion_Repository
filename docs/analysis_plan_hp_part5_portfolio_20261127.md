# 分析方案第五部分：跨城持有能分散多少下跌风险（2026-11-27）

状态：**已锁定**，SHA-256 见 `docs/plan_locks.md`。锁定后才写运行脚本。锁定后的改动只追加在文末“偏离记录”里，正文不动。

## 1. 问题

论文主问题：**这一轮全国楼市下行中，跨城持有住房能分散哪些房价下跌风险？** 第一至第三部分回答“哪些风险”：全国共同部分分散不掉，城市自身的累计偏离可以分散。本部分回答“能分散多少”，以及“在全国大跌的月份里，分散是否失效”。做法是用同样的本金和持有期，比较持有 1 个城市和持有多个城市的假想组合。随机抽组合的做法参照 Evans 和 Archer (1968)；单城与组合的对比参照 Higgins 和 Fang (2012) 表 9；指标换成累计跌幅、坏月份跌幅和分位数回归。

这里的组合是假想的：用国家统计局二手房指数代表各城房价，等权买入，不计租金、税费和交易成本。单套房子自身的风险比城市指数大得多，所以结果只衡量城市之间能分散的部分。

## 3. 数据与组合构造

- **价格**：CSMAR 的国家统计局 70 城二手住宅月度环比指数，用原始值，不去季节。城市 i 在月 t 的对数变化 yᵢₜ = 100·ln(环比指数/100)，与 `hp_lib.load_panel` 一致。价格水平 Pᵢₜ 由环比连乘得到。
- **城市**：组合分析用全部 70 城；用到城市实力指数 S 的检验（H-P4）用 69 城，与第二部分相同。
- **下行期 D**：2021-07 末等额买入，持有到 2026-10，共 63 个月（2021-08 至 2026-10），令 2021-07 的 Pᵢ = 1。稳健性：从 2021-12 末买入，与锁定的 P3 窗口一致。
- **上行期 U**（只用于 H-P6）：2015-03 末买入，持有到 2021-07，共 76 个月（2015-04 至 2021-07），令 2015-03 的 Pᵢ = 1。D 与 U 的划分取自附录 A 的拐点。
- **持有城市数** n ∈ {1, 2, 3, 5, 10, 20, 35, 70}。n = 1 枚举全部 70 城，n = 70 只有一个组合；其余每个 n 不放回地随机抽 10,000 个城市组合，种子 20261127。分位数回归只用每个 n 的前 2,000 个组合（计算量），且不做 n = 70（见 4(c)）。
- **买入持有组合**（用于 4(a)(b)、H-P3 的累计跌幅与期望损失、H-P6）：等权买入后不再调仓，组合价值 Vₚₜ = (1/n) Σᵢ∈ₚ Pᵢₜ，月收益 rₚₜ = Vₚₜ / Vₚ,ₜ₋₁ − 1（%）。稳健性：每月调回等权。
- **等权平均组合**（只用于分位数回归，4(c) 和 H-P3 的距离保留比）：yₚₜ = (1/n) Σᵢ∈ₚ yᵢₜ，即成员城市月度对数变化的简单平均（相当于每月调回等权）。这样组合与单城的差别只来自“取平均”，n = 1 时与单城完全相同。

## 4. 统计量

**(a) 整轮累计跌幅（选城风险）**

- 组合累计跌幅 Lₚ = 1 − Vₚ,2026-10（%）。
- 对每个 n 报告：Lₚ 的均值、中位数、第 90 百分位，以及**最差一成组合的平均跌幅** CVaR₁₀(n)。
- **主统计量**：Δ_cross(n) = CVaR₁₀(1) − CVaR₁₀(n)，即持有 n 城比只持有 1 城，在选城最不利的一成情形下整轮少跌多少个百分点。同时报告相对降幅 Δ_cross(n) / CVaR₁₀(1)。
- 同时报告均值的变化。等权买入持有不改变平均跌幅，这一点在正文中说明。

**(b) 坏月份跌幅（时间风险）**

- 每个组合（或城市）的期望损失 ES₁₀：63 个月里最差 6 个月（k = ⌊0.1T⌋）的月收益平均值。
- **描述统计量**：Δ_time(n) = 均值ᵢ ES₁₀(城市 i) − 均值ₚ ES₁₀(组合 p)，即坏月份平均少跌多少个百分点。
- **稳健性 R1（原比值检验）**：对每个组合定义尾部距离 Gₚ = μₚ − ES₁₀,ₚ（自身月均值与最差 6 个月平均值之差）和标准差 σₚ，比较
  - 坏月份比值 ρ_bad(n) = 均值ₚ Gₚ / 均值ₚ [组合 p 各成员城市 Gᵢ 的平均]；
  - 全部月份比值 ρ_sd(n) = 均值ₚ σₚ / 均值ₚ [组合 p 各成员城市 σᵢ 的平均]。

  各城收益服从任一椭圆分布时 ρ_bad = ρ_sd。报告 ρ_bad(10) − ρ_sd(10) 减去正态模拟均值后的值：按 70 城样本均值和样本协方差抽多元正态序列（63 个月，999 次，种子 20261127），用同一批组合计算。镜像统计量用最好 6 个月计算，作对照。R1 与 H-P2 问的是同一件事，用作 H-P2 的稳健性，不单独判定。

**(c) 组合与单城的分位数回归（H-P2，主检验）**

*模型。* 对每个城市（n = 1）和每个组合（n ≥ 2），用同一个式子：

Q_τ(yₚₜ | ·) = aₚ(τ) + βₚ⁺(τ)·hₚₜ + βₚ⁻(τ)·gₚₜ + dₚ(τ)·yₚ,ₜ₋₁

- fₚₜ：**不含组合成员城市**的其余 70 − n 城 yⱼₜ 的等权平均。n = 1 时就是第一部分的“其余 69 城均值”。剔除成员是为了避免 n 越大、组合越接近全国均值而斜率机械地趋近 1；剔除后因子由 70 − n 城构成，所以 n 最多取 35，n = 70 不做回归。
- hₚₜ = max(fₚₜ, 0)（全国涨幅），gₚₜ = max(−fₚₜ, 0)（全国跌幅）。这与 H4 的“f 加 |f|”是同一个模型的重新参数化：b·f + c·|f| = (b + c)·h + (c − b)·g。分段写法让“全国跌的月份”单独有自己的斜率。
- τ ∈ {0.25, 0.5, 0.75}。下行期只有 63 个月，τ = 0.25 以下约 16 个月，所以不用 τ = 0.1。
- **样本：全样本 2011-02 至 2026-10**（滞后项用到 2011-01），T = 189。只用下行期时 f 几乎每月为负，h 几乎全为 0，涨与跌分不开，所以主检验用全样本。

*由系数得到的量（每个城市或组合各一个）：*

- 坏端斜率 λ(τ) = −β⁻(τ)：全国每多跌 1 个百分点，第 τ 分位跟着下移多少。
- 平时的坏端距离 w₀ = a(0.5) − a(0.25)：全国不涨不跌、上月为 0 时，中位数与坏端的距离。
- **全国下跌时的变宽** ω = λ(0.25) − λ(0.5) = β⁻(0.5) − β⁻(0.25)：全国每多跌 1 个百分点，中位数与坏端的距离拉宽多少。
- 上尾镜像：w₀⁺ = a(0.75) − a(0.5)，ω⁺ = β⁺(0.75) − β⁺(0.5)（全国上涨时上端变宽多少），作对照。

*保留比（对每个 n）：*

- R_w(n) = 均值ₚ w₀,ₚ / 均值ₚ [组合 p 各成员城市 w₀,ᵢ 的平均]：持有 n 城后，平时的坏端距离还剩几成。
- R_ω(n) = 均值ₚ ωₚ / 均值ₚ [组合 p 各成员城市 ωᵢ 的平均]：全国下跌时的变宽还剩几成。
- **主统计量：θ(10) = R_ω(10) − R_w(10)。**

*为什么比两个保留比，而不是直接比 ωₚ 和单城 ω。* 取平均本身就会让所有宽度变窄，所以“组合的 ω 比单城小”在各城冲击相互独立时也会出现，区分不了“正常分散”和“分散失效”。如果城市自身冲击的大小随全国跌幅同比例放大、而城市之间冲击的相关程度不随全国跌幅变化，那么取平均对“平时的宽度”和“下跌时的变宽”打的折扣相同，θ 近似为 0（各城放大比例不同时会有小的偏差）。θ > 0 说明全国下跌时新增的那部分分化在组合里留得更多，也就是大跌时各城自身的冲击会一起出现，分散在最需要的时候打折扣。这是 R1 中 ρ_bad − ρ_sd 的分位数回归版本。

*闸门。* 如果单城平均 ω̄（n = 1）的 95% 区间下限不大于 0，说明全样本里单城层面看不到全国下跌时的变宽，R_ω 的分母接近 0，H-P2 无从检验，只报告描述统计。

*描述部分（不另做判定）：*

- 对 n ∈ {1, 2, 3, 5, 10, 20, 35} 报告 λ(0.25)、λ(0.5)、w₀、ω、R_w、R_ω 随 n 的曲线，上尾镜像同样报告，并报告 Δω(10) = ω̄(城市) − ω̄(组合)。
- **独立冲击基准**：对每个城市取全样本中位数回归的残差，每城的残差序列各自做随机循环平移（平移量独立抽取），加回该城的中位数拟合值，得到“各城自身冲击互不相关”的模拟数据；fₚₜ 保持原值。在模拟数据上对 n = 10 的前 300 个组合重算 R_w，重复 199 次，种子 20261127。实际 R_w(10) 高于基准，说明扣除全国因子之后，各城的冲击仍然成群出现。循环平移也打断了残差与 f 的对应，所以这个基准只用于 R_w，不用于 R_ω。
- **下行期内的斜率**：在 D（2021-08 至 2026-10，T = 63）内估计 Q_τ = a + b·f + d·y₋₁（与 H4 的 P3 设定相同），对每个 n 报告 b(0.25)、b(0.5) 和平均拟合距离（各月 Q̂₀.₅ − Q̂₀.₂₅ 的平均）。

*稳健性：* n = 5 和 n = 20 的 θ；去掉滞后项；R1。

**(d) 同区域与跨区域（H-P3）**

区域按国家统计局四大区域划分（东部 28 城、中部 16 城、西部 18 城、东北 8 城，与 `hp_lib.REGION` 一致），n = 5。

- 同区域组合：先按各区域城市数的比例抽一个区域，再在区域内随机抽 5 城。
- 跨区域组合：从 70 城中随机抽 5 城，只保留覆盖至少 3 个区域的组合。
- 两类各 10,000 个。比较两者的 CVaR₁₀(L) 和平均 ES₁₀；分位数回归按 4(c) 的设定，用每类前 2,000 个组合比较 R_w(5)。按区域分别报告同区域组合的结果。
- 判定用 CVaR₁₀(L) 之差（跨区域减同区域），ES 与 R_w 作描述。

**(e) 止跌时间（H-P4，思路来自研报，见研究计划 3.10）**

- 每个城市最近 6 个月（2026-05 至 2026-10）的累计对数变化 R6ᵢ。
- 每个城市累计价格的谷底月份。谷底在 2026-10 的，记为尚未见底。
- 检验 ρ(S, R6) > 0（实力强的城市先止跌），69 城。另按 S 三等分组报告已见底城市占比。

**(f) 能否事先识别重跌城市（H-P5）**

- 事前敏感度 β_preᵢ：用 2011-01 至 2021-07 的数据估计 yᵢₜ = aᵢ + βᵢ f₋ᵢ,ₜ + eᵢₜ。
- 检验 ρ(β_pre, −D) > 0。同时报告跌得最深的四分之一城市与事前最敏感的四分之一城市的重合数，对照随机期望。
- 再报告一个简单的事前规则：按 β_pre 最低的 10 城等权持有，其 L 落在随机 10 城组合分布的第几百分位。

**(g) 上行期与下行期的分散效果（H-P6）**

- 在 U 和 D 中，用同一批 n = 10 的城市组合（同一组城市代码）构造各自的买入持有组合，k = ⌊0.1T⌋：U 为 7 个月，D 为 6 个月。
- 对每个窗口计算 R1 中的坏月份比值 ρ_bad(10)，即坏月份尾部距离在组合中还剩几成。
- **统计量**：ρ_bad,D(10) − ρ_bad,U(10)。大于 0 说明下行期坏月份的分散效果比上行期差。同时报告两个窗口的 ρ_sd(10) 及其差，作对照。

## 5. 推断

- **(a) 与 H-P3 的累计跌幅统计量**：只对城市重抽（有放回抽 70 城，在重抽后的城市集合里重新随机抽组合，每次 2,000 个），B = 999，种子 20261127。整轮跌幅是已发生的量，这里的不确定性来自“样本是这 70 个城市”。
- **(b) 的坏月份统计量与 R1**：所有城市共用同一组 6 个月块做循环移动块自助，组合固定为 2,000 个，B = 999。
- **H-P2**：对全样本 189 个月做 6 个月块的循环移动块自助，所有城市共用同一组块，每月的 y、滞后项和因子一起抽（与 H4 相同）。每次抽样中，70 个城市和 n = 10 的前 300 个组合全部重新估计，θ(10)、R_ω(10)、R_w(10) 和 ω̄ 在同一次抽样里计算，用差值构造区间。B = 499，种子 20261127。描述曲线只报告点估计。
- **H-P4、H-P5**：城市重抽，S 和 β_pre 在每次抽样中重新估计；另报告双向自助（月份块 + 城市）的区间作对照。
- **H-P6**：U 和 D 各自独立做 6 个月块的循环移动块自助（两个窗口的块互不相关），组合固定为前 2,000 个，B = 999。
- 报告点估计、自助标准误和双侧 95% 百分位区间。单侧假设按区间下限是否大于 0 判定。
