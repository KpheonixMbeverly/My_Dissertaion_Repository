# 分析方案锁定（第三部分）：分位数因子——下跌期城市间的共同变动，在下尾是否更强？（2026-11-24）

本文件在分位数因子模型正式估计前写定，是 `analysis_plan_hp_20261124.md`（第一部分）和 `analysis_plan_hp_part2_hetero_20261124.md`（第三章）的续篇。数据、变量 y 和时期定义沿用第一部分。此后改动只记入文末"偏离记录"。

**事先披露。** 写定本方案时，**还没有在 70 城数据上估计过任何分位数因子模型**，下列所有统计量都尚未看过。假设方向参考了第一部分已知的结果：

- 同步波动份额（S_dm）和第一主成分占比在 2011–15 年最高、2016–21 年最低；
- 同时深跌概率没有超出高斯基准；
- 下尾斜率上升主要是尺度效应（H4）。

因此 QF1 的方向事先就知道会受尺度效应影响，真正的判别检验是 QF2。

## 1. 模型与估计

对每个时期 p（P1 = 2011-01 — 2015-12，P2 = 2016-01 — 2021-12，P3 = 2022-01 — 2026-10）、每个市场、每个分位数 τ，估计一因子分位数因子模型（Chen, Dolado & Gonzalo, 2021, Econometrica 89(2):875–910）：

  Q_τ(yᵢₜ | fₜ(τ)) = αᵢ(τ) + λᵢ(τ) · fₜ(τ)

αᵢ(τ) 是城市自身的分位数水平，所以因子刻画的是"各城围绕自身水平的共同变动"，对应第一部分的同步波动（S_dm），而不是共同趋势。

**估计（QFA 迭代分位数回归，CDG 2021 第 3.1 节）**：

1. 初值两个：(a) 当月 70 城均值；(b) 各城去均值后的第一主成分。
2. 给定 f，逐城求 (αᵢ, λᵢ) 的分位数回归；给定 (α, λ)，逐月求 fₜ 的分位数回归。交替进行。
3. 当目标函数的相对下降小于 10⁻¹⁰，或达到 500 次迭代时停止。两个初值中保留目标函数更低的一个。
4. 标准化：fₜ 在期内均值为 0、均方为 1；符号使 λ 的平均值为正。

两步都用精确解：

- 城市步只有两个参数，最优解必在某两个观测点的插值线上，枚举全部点对。
- 月份步只有一个参数，目标是分段线性凸函数，枚举全部折点。

正式运行前，先用 HiGHS 线性规划核对这两个精确解（相对误差 < 10⁻⁸）。

## 2. 统计量

- 基准损失 V₀ₚ(τ) = Σᵢ Σₜ ρ_τ(yᵢₜ − q̂ᵢ(τ))，其中 q̂ᵢ(τ) 是城市 i 在期内的 τ 分位数。
- 因子模型损失 V₁ₚ(τ) = QFA 的目标函数值。
- **分位数共同因子份额** R¹ₚ(τ) = 1 − V₁ₚ(τ) / V₀ₚ(τ)：一个共同因子能解释多少该分位数上的城市变动（检验损失意义下）。
- **尾部不对称** Aqₚ = R¹ₚ(0.25) − R¹ₚ(0.75)。

ρ_τ(u) = u · (τ − 1{u < 0}) 为分位数回归的检验函数。

## 3. 假设（二手房为主，新房为半独立重复）

- **QF1 下尾同步更强（P3）**：Aq_P3 > 0。
  - 提醒：下跌期全国因子几乎总为负，若城市间离散度随全国跌幅扩大（尺度效应），下尾份额会机械地更高。所以 QF1 成立本身不足以说明"下跌特有"。
- **QF2 超出镜像（主要判别检验）**：Aq_P3 + Aq_P2 > 0。
  - 理由：若只有尺度效应，繁荣期（P2，因子多为正）应出现方向相反、幅度相近的不对称（上尾份额更高），两者相加约为 0。
  - 二者之和显著为正，才说明下跌期的下尾同步超出了尺度效应的镜像。
  - 另报告 Aq_P1（涨跌两个方向都有的时期）。
- **QF3 下跌期下尾同步是否增强**（双侧，无方向假设）：R¹_P3(0.25) − R¹_P1(0.25)；R¹_P3(0.25) − R¹_P2(0.25)。
- **QF4 上下尾是否由同一个共同冲击驱动**（P3，描述性）：
  - corr(f̂(0.25), f̂(0.75))、corr(f̂(0.25), f̂(0.50))、corr(f̂(0.75), f̂(0.50))；
  - 各分位数因子与当月 70 城均值的相关；
  - 各分位数因子与当月城市间四分位距的相关。
- **QF5 第二个因子**（只报点估计）：
  - 两因子模型相对一因子模型的增量份额 ΔR¹ₚ(τ) = (V₁ₚ − V₂ₚ) / V₀ₚ；τ ∈ {0.10, 0.25, 0.50, 0.75, 0.90}；P1、P2、P3 和全样本。
  - 用于判断尾部是否有均值因子之外的共同因子。两因子模型的城市步用 HiGHS 线性规划。
- **描述性对照**：R¹ₚ(0.50) 在三期的排序是否与第一部分的 S_dm 一致。

## 4. 推断

- 时期内循环移动块自助法：块长 6 个月；70 城和两个市场用同一组月份；各时期独立抽样。
- 每次抽样都重新估计 QFA：初值为点估计中对应月份的因子，另加当月均值初值，保留目标函数更低的一个。
- B = 499（受计算量限制，少于第一部分的 999）。
- 报告点估计、自助标准误、双侧 95% 百分位区间、MDE = 2.5 × 标准误。
- "支持" = 区间不含 0 且方向与假设一致。

## 5. 稳健性（点估计，不参与判定）

1. τ 改为 0.10 / 0.90。
2. 去季节数据。
3. 3 个月累计涨跌。
4. 两因子模型下的 R¹ 和 Aq。
5. 剔除 4 个一线城市。

本部分不做块长稳健性（计算量）。

## 6. 判定规则

按顺序对照，第一条符合的即为结论：

| 顺序 | 结果 | 结论 |
|---|---|---|
| 1 | QF2 支持 | 下跌期下尾的共同变动超出尺度效应的镜像：存在下跌特有的尾部同步 |
| 2 | QF1 支持，QF2 不支持 | 下尾的共同因子份额更高，但与尺度效应（繁荣期的镜像）相容，不能说是下跌特有 |
| 3 | QF1 不支持 | 在分位数因子层面也没有"下尾更同步"的证据，与第一部分 H3 一致 |

QF3、QF4、QF5 单独报告，不改变上述结论。新房结果与二手房方向相反时写明，不改判定。
